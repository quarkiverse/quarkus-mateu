[.description]
--
Keep the beans that Mateu injects into the view models it instantiates itself. Mateu creates a routed view model per request and fills its `@Inject` fields from the container, so ArC sees no injection point for those services and would remove them as unused. When enabled, the extension marks the types of those injection points, and every bean implementing a Mateu interface (`CrudStore`, `ListingExporter`, `PrincipalResolver`...), as unremovable.
